RocksDB now sets `IOOptions::type` to `IOType::kManifest` for IO on MANIFEST files and to `IOType::kMetadata` for IO on CURRENT, IDENTITY and OPTIONS files (including the `FileOptions::io_options` used to open them), so a `FileSystem` can treat this IO differently from bulk data IO, e.g. give it a higher priority. `ReadFileToString()` with an `IOOptions` argument now also uses its `type` to open the file.
