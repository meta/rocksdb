Added experimental option `enable_blob_indirection` and indirect blob GC: with it and `enable_blob_garbage_collection`, background jobs move the live values out of blob files that have a lot of garbage without rewriting SSTs. Related options: `blob_indirection_max_references_per_sst`, `indirect_blob_gc_read_coalesce_bytes`, `indirect_blob_gc_garbage_ratio` (the smallest garbage ratio of a blob file that GC rewrites, default 0.5), `pin_blob_relocation_location_blocks`. Once a column family uses it, releases that do not know the format cannot open the DB. RepairDB returns NotSupported for a DB that has blob indirection data.
