Added experimental option `enable_blob_indirection` and indirect blob GC: with it and `enable_blob_garbage_collection`, background jobs move the live values out of blob files that have a lot of garbage without rewriting SSTs. New statistics (`INDIRECT_BLOB_GC_*`, `BLOB_RELOCATION_*` and others) and DB properties (`rocksdb.indirect-blob-gc-stats` and others) report its work. Once a column family uses it, releases that do not know the format cannot open the DB. RepairDB returns NotSupported for a DB that has blob indirection data. Ingesting an SST file that a DB wrote with the option on returns NotSupported.
