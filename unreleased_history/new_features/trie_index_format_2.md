The experimental trie index factory takes a `format_version` (`user_defined_index_factory={id=trie_index;format_version=2}`). Format 2 is much smaller and faster to search than format 1 and has no 4 GiB data-block offset limit. Earlier RocksDB versions fail to open SST files with format 2 trie indexes, so switch back to format 1 and compact before downgrading. Format 1 remains the default, and both formats are readable.
