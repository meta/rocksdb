Added the experimental option `DBOptions::manifest_store_shadow`. With `DBOptions::manifest_store` set, the MANIFEST file stays the authority and RocksDB also commits each MANIFEST write to the store in the background, so that an application can check a metadata store before it moves a DB into it. The first MANIFEST write while shadow mode is on, usually inside `DB::Open()`, starts a new MANIFEST file, also with `reuse_manifest_on_open`. The new `ldb compare_manifest_store` command lists the differences between the store and the MANIFEST of a closed DB.
