In forward and reverse scans, read-path range tombstone conversion (`min_tombstones_for_range_conversion`) now also counts the point keys that a range tombstone in the same immutable memtable or SST file already covers. The new range tombstone in the mutable memtable then covers those keys too, so later scans skip them with one seek instead of stepping over each key. Because the threshold now counts these keys too, conversions can happen earlier and more often.
