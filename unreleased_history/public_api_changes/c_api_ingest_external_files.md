Added `rocksdb_ingest_external_files()` and the `rocksdb_ingestexternalfilearg_t` type to the C API, exposing `DB::IngestExternalFiles()` and `IngestExternalFileArg`. C API users can now atomically ingest files into multiple column families, and can supply per-file checksums and checksum function names (`files_checksums` / `files_checksum_func_names`) so that, with `verify_file_checksum` disabled, the DB records the given checksums instead of reading each file to generate them.
