Added two-phase external file ingestion to the C API: `rocksdb_prepare_file_ingestion()`, `rocksdb_commit_file_ingestion_handles()` and `rocksdb_fileingestionhandle_destroy()`, exposing `DB::PrepareFileIngestion()` and `DB::CommitFileIngestionHandles()`. Committing takes ownership of the handles whether it succeeds or fails; destroying a handle that was never committed rolls its ingestion back.
