Added the experimental `DBOptions::manifest_store` and `DBOptions::manifest_row_feature_version` options and the `ManifestStore` interface (`include/rocksdb/manifest_store.h`) for keeping MANIFEST metadata in an external store. This release does not support store mode: every DB open function returns `NotSupported` when `manifest_store` is set, or `InvalidArgument` when `manifest_store` is set and `manifest_row_feature_version` is not a supported value. New OPTIONS files have a `manifest_row_feature_version` line.
