Added experimental store mode: with `DBOptions::manifest_store` (see `include/rocksdb/manifest_store.h`), `DB::Open()` keeps the MANIFEST metadata of a DB as rows in an external store. The new options `DBOptions::manifest_store_migrate` and `DBOptions::manifest_store_copy_mode` and the new function `RollBackManifestStore()` move a DB into the store and back to file mode. Some paths, for example checkpoints, backups and secondary instances, return `NotSupported` in store mode. `DestroyDB()` now reads CURRENT: it returns `NotSupported` for a DB in store mode, and it returns the I/O error and deletes nothing when an I/O error other than a missing file stops it from reading CURRENT or the MANIFEST that CURRENT names, and the folder can be listed. It also deletes leftover MANIFEST file copies. New OPTIONS files have a `manifest_row_feature_version` line.
