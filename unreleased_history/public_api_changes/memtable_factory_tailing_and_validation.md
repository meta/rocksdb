Added `MemTableRepFactory::IsTailingIteratorSupported()`; tailing iterators now fail with `NotSupported`, and `Iterator::Refresh()` always rebuilds memtable iterators, on column families whose memtable factory returns false. `MemTableRepFactory::ValidateOptions()` is now also checked by `CreateColumnFamily()`, `SetOptions()`, and `SetDBOptions()` (for every column family), not only `DB::Open()`, so a custom factory that rejects a column family's options also makes those calls fail. It may be called with the DB mutex held, so it must not call back into the DB.
