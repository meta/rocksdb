Fixed remote compaction (`DB::OpenAndCompact()`) writing output files without the column family's prefix filter when `CompactionServiceOptionsOverride::prefix_extractor` was not set. The worker replaced the prefix extractor from the primary's OPTIONS file (and from `options_map`) with null, so prefix seeks could not skip those files. The worker now keeps the OPTIONS file's prefix extractor unless the override sets one, provided the worker can create it. If it cannot, for example a custom extractor that is not registered on the worker, the worker logs a warning and the output files have no prefix filter.
