Fixed `CompactionFileInfo::level` for the entries of `CompactionJobInfo::input_file_infos` (passed to `EventListener` compaction callbacks), which reported the position of the file's input level within the compaction (0, 1, ...) rather than its LSM level. Levels were correct for L0 input files, and for all input files of an L0-to-L1 compaction, but typically wrong for other input files.
