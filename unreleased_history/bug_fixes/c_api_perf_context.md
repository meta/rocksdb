Fixed the C API perf level constants for `rocksdb_set_perf_level()`, which no longer matched `PerfLevel` after it gained new levels. For example, `rocksdb_enable_time` selected `kEnableTimeExceptForMutex`. Added the missing `rocksdb_enable_wait` and `rocksdb_enable_time_and_cpu_time_except_for_mutex` to the C API, and `PerfLevel.ENABLE_WAIT` to the Java API. Also fixed `rocksdb_perfcontext_metric()` always returning 0 for `rocksdb_blob_cache_read_byte`, and `rocksdb_total_metric_count` being 2 higher than the number of metrics.
