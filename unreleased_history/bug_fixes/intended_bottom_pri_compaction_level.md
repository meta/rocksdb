Fixed a bug where, with a bottom-priority thread pool and `CompactionOptionsUniversal::reduce_file_locking` (default true), a compaction waiting for a bottom-priority thread tracked its input files under the wrong level. With leveled compaction this could block L0 compactions while it waited, and with `preclude_last_level_data_seconds` it could cause a debug assertion failure in `CompactionPicker::RegisterCompaction`.
