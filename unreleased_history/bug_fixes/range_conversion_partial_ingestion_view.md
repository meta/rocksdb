Fixed a bug where, with `min_tombstones_for_range_conversion` enabled, an iterator, `MultiGet()` or `Iterator::Refresh()` that ran at the same time as `IngestExternalFile()` could see only part of the ingestion: a range tombstone that another iterator inserted could hide a key that the ingested file deletes, while the read did not see the other keys of that file. Such a read now uses the SuperVersion that has the ingested files.
