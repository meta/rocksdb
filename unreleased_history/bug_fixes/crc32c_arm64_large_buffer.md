Fixed CRC32C on 64-bit ARM with hardware CRC (e.g. Linux aarch64, macOS arm64) for a single buffer of 2 GiB or more, which skipped all or most of the data. With a value of 2 GiB or more, this made reads with `checksum = kCRC32c` fail with a false block checksum mismatch, let corruption of a blob value go undetected, and made `VerifyFileChecksums()` report a false mismatch with `GetFileChecksumGenCrc32cFactory()`.
