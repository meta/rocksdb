`BackupEngine::CreateNewBackup()` now re-enables file deletions once it has copied the WAL, MANIFEST, CURRENT and OPTIONS files, while it keeps the table and blob files it has yet to copy, instead of after the last table file. Obsolete WAL files are then deleted during the rest of the backup instead of accumulating until it ends. Closing the DB while `CreateNewBackup()` is running is not supported.
